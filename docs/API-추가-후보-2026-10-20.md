# API 추가 후보 (2026-10-20)

지금 쓰는 것: 서울 실시간 도시데이터, 공공데이터포털(기상청 단기·중기, 특일, 관광공사 집중률·연관관광지·TourAPI·DataLab, 인천·한국공항공사, 에어코리아, 부산 생활인구), ThemeParks.wiki(에버랜드·롯데월드), 파파고, 네이버 지도, 카카오·네이버·구글 로그인, 토스페이먼츠, Resend, Upstash, Neon.

## 우선순위 높음 (효과 큼, 비용 0원)

| API | 어디서 | 얻는 것 | 할 일 |
|---|---|---|---|
| **TourAPI 다국어** (EngService2 · JpnService2 · ChsService2 · ChtService2) | 공공데이터포털 활용신청 | 명소 이름·설명을 관광공사 공식 외국어로 → **파파고 사용량 크게 감소**, 번역 품질 ↑ | 사용자: 4개 활용신청 (같은 DATA_GO_KR_KEY) → 저: 스크립트에 붙이기 |
| **공공데이터 운영계정 전환** | 공공데이터포털 (개발계정 → 운영계정) | 하루 호출 한도 상향 (지금 개발계정 한도로 90%에서 멈춤 장치) | 사용자: 활용사례 등록 후 운영 신청 (진행 중) |
| **서울 실시간 지하철 도착** (realtimeStationArrival) | 서울 열린데이터광장, **별도 실시간 지하철 키** | 코스·장소에서 가까운 역 다음 열차 시간 | 사용자: 실시간 지하철 인증키 신청 |
| **인천공항 주차장 실시간** (15095047) | 공공데이터포털 | 공항 주차 탭의 빈자리 정확도 | 사용자: 활용신청 |
