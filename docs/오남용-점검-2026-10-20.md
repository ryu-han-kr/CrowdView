## 4. 직접 하실 일 (콘솔 설정)

1. **네이버 클라우드 지도 키 도메인 제한**: NCP 콘솔 > AI·NAVER API > Application > 지도 앱 > 'Web 서비스 URL'에 `https://crowdview.app` (와 `http://localhost:3000`)만 있는지 확인. 지도 키는 브라우저에 보이는 값이라, 제한이 없으면 남의 사이트가 우리 키로 지도를 띄우고 요금은 우리가 냄
2. **Vercel Firewall 규칙 (선택, Pro 포함)**: Vercel > crowdview > Firewall > Rate Limiting에 `/api/` 경로 IP당 1분 120회 규칙 하나. 코드의 제한보다 앞단에서 막아 함수 실행 자체가 안 생김
3. **심사용 계정 삭제**: 토스 심사가 끝나면 `npx tsx scripts/review-account.ts delete` (제가 해도 돼요)
4. **Toss 가맹점 관리자 알림**: 이상 거래 알림 수신 이메일이 hks.han666@gmail.com 으로 되어 있는지 확인
