### QA 검수 결과 (2026-10-18)
- 운영 사이트를 PC·모바일, 라이트·다크로 찍고, 코스 만들기 → 장소 → 뒤로 가기, 막대 선택·더보기, 가이드 지도를 실제로 눌러 확인 (CDP 스크립트)
- QA 1~10 모두 반영 확인. 남은 제약: 로그인 실동작(키 필요), 121곳 넘는 실시간(SK 키 필요), 관광공사 명소 외국어 소개(외국어 TourAPI 신청 필요)
- 익스피디아·호텔스닷컴 링크는 서버에서 확인하면 429(봇 차단)지만 브라우저에서는 열림

### 알아 둘 것
- **로컬에서 네이버 지도 화면이 "This page couldn't load"로 멈춤**: 지도 키가 운영 주소에만 등록돼 있어 생기는 일 (운영은 정상). 로컬 확인은 `NEXT_PUBLIC_NAVER_MAP_CLIENT_ID= npx next build` 로 지도 없이(대체 그림) 빌드
- 로컬 화면 확인: headless Chrome + CDP 스크립트(클릭·이동 후 캡처)가 편함 — 이번 세션 방식
- 서울시 실시간 도시데이터는 121곳이 최대 (POI001~131 중 폐지 코드 제외). 더 많은 지점은 SK open API 장소 혼잡도(키 필요) 또는 서울 생활인구(행정동, 하루 늦음)
