## 3. 다음 할 일 — 사용자가 승인한 UI·QA 도구 적용 (순서대로)

사용자 결정 (2026-10-19): **아래 4가지 모두 진행, 휴대폰 화면(앱 UI)도 같이 바꿔도 됨** (레이아웃 배치는 유지, 아이콘·여백·글자·색 정리).
**화면이 바뀌는 단계(2·3)는 전·후 스크린샷(휴대폰 375px · PC 1280px)을 보여 주고 승인받은 뒤 머지.**

1. **Playwright + Lighthouse CI (안전장치 먼저)**
   - Playwright: 주요 화면(홈·장소 상세·지도·코스·서울·마이·요금) 열림 + 결제 확인 창 동작 E2E, Chromium·WebKit, 휴대폰·PC 스크린샷 비교(실시간 숫자 영역은 가림)
   - Lighthouse CI: 운영 배포 후 점수 측정, 처음엔 경고만 (배포 차단 X)
   - GitHub Actions에 붙이기 (PR마다 / 배포 후)
2. **Lucide 아이콘 교체**: 이모지 아이콘 347개(58개 파일: 🌧 😷 ✈ 🔔 📍 ☆ 🤍 ✕ 등) → `lucide-react`. 날씨·감정처럼 이모지가 더 나은 곳만 남김
3. **shadcn/ui 일부 + Refactoring UI 원칙으로 디자인 정리**
   - shadcn: Dialog/Sheet(ConfirmSheet 교체, 포커스 가두기), Tabs, Tooltip, Toast 정도만. 전체 교체 X
   - 여백 간격·글자 크기/굵기 단계·색·그림자 정리: 홈 → 장소 상세 → 지도 → 마이페이지 순
   - 다크 모드 색은 `scripts/dark-css.py` → `src/app/dark.css`
4. **Sentry** (무료 Developer 플랜): 오류 추적 + 세션 리플레이
   - 사용자가 sentry.io 가입 후 DSN을 Vercel에 넣어야 함 (`NEXT_PUBLIC_SENTRY_DSN` 등)
   - 세션 리플레이는 화면 녹화라 **개인정보처리방침에 Sentry(미국) 국외 이전 추가**, 입력칸·개인정보 마스킹
   - 기존 `ErrorReporter`(디스코드 알림)는 유지할지 정리할지 판단
   - 하지 않기로 한 것: BrowserStack(유료), Tailwind Plus 구매($299), Mobbin(유료 계정) — 참고만
