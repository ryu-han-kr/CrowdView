## 새 채팅 첫 메시지 (여기부터 복사)

CrowdView(Next.js 16, 저장소 ryu-han-kr/CrowdView, 운영 https://crowdview.app)를 이어서 작업한다. **한국어로 답하고**, 처음 하는 사람에게 설명하듯 쉽게 써 줘. 나는 SA(솔루션 아키텍트)가 목표라 지금은 Vercel로 운영하지만 나중에 직접 클라우드로 옮길 예정이니, 특정 플랫폼에 묶이지 않는 구조를 선호한다. 비밀 키는 채팅에 붙여넣지 않고 .env.local / Vercel 환경변수 / GitHub Secrets에 넣는다. 작업은 묻지 말고 브랜치 → PR → CI 통과 → 머지까지 진행해. 먼저 `docs/handoff/` 에서 가장 최근 파일(지금은 `2026-10-17_3.md`)과 `docs/review/index.html`(외부 검토 종합·진행 결과)을 읽고 이어서 해 줘. 오늘 날짜가 2026-10-23 이후면 Upstash 사용량 확인부터 알려 줘.

### 원칙 (외부 AI 검토 3종 합의)
- 기능 추가보다 **데이터 신뢰성 → 방문 가능한 추천 → 검색로봇이 읽는 본문 → 운영 안전 → 전환·수익화 → 다국어·전국 확대** 순서
- '실시간'은 실측에만. 추정·예측·지역 통계는 화면에 그렇게 표시. 서울시 데이터가 있는 곳은 서울시 공식 단계(같은 관측값)
- 추천 시간은 운영 시간 안에서만, 마감 직전엔 추천하지 않음
- 포지셔닝 후보: "혼잡을 피해 이동하는 여행 도우미"
