## 3. 조사 결과

- **롯데월드 대기시간**: 홈페이지 API `/api/today/attraction-waits?storeCd=HC01801&langCd=HC01701`는 개장 중에도 빈 목록, 운휴 목록 `/api/today/closed-list`·운영시간은 나옴. Queue-Times(333)도 운영 여부만, 대기시간 전부 0(10~11월 자료 없음) → **롯데월드가 대기시간 공개를 멈춘 것으로 보임**. 정확하게 하려면 SKT(사용자가 받아 오겠다고 함)
- **Queue-Times**: 에버랜드(125) 실제 대기시간 나옴(57개 중 47 운영). 레고랜드 315, 캐리비안 베이 329. 쓰려면 "Powered by Queue-Times.com" 표기. 지금 ThemeParks.wiki의 예비 원천 후보
- **100대 명산**: 산림청_산정보 서비스(15058662, `apis.data.go.kr/1400000/service/cultureInfoService2/mntInfoOpenAPI2`)는 지금 키로 "등록되지 않은 서비스키" → **사용자 활용신청 필요**. 선택: 100대명산 봉우리POI(15097953, 위도·경도). 승인되면 100곳 목록 → 관광공사 사진·좌표로 명소 추가(오늘 넣은 산 13곳과 겹침 처리)
- **실제 수치 비교로 모델 고치기(사용자 요청, 다음 작업)**: 매일 새벽 '어제 예측 vs 실제' 장소별 오차 기록 → 보정 계수 조금씩 갱신 → 관리자 화면 정확도 표. 실제 자료: 데이터랩 시군구 일별 방문객(연결됨), 서울 지역 인구·대기시간·공항(쌓는 중), 주요관광지점 입장객 월별(전국 API 없음 — 관광지식정보시스템 파일, 경남 15095836·서울 4대궁 OA-12411 등 지자체 API)
- 사용자가 붙여 준 추천 글(`message.txt`, 15KB)이 잘려서 뒷부분 "수학적 모델 적용 표"를 못 봄 → **새 채팅에서 다시 받기**
