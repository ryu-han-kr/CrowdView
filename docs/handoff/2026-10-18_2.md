## 3. 내일 사용자가 할 일 (순서대로, 체크하면서)

> 비밀 키는 채팅에 붙여넣지 말고 Vercel 환경변수 / `.env.local` / GitHub Secrets에만 넣어 주세요.
> 1~3번을 하면 로그인·회원가입·마이페이지 동기화가 바로 켜져요.

### □ 1. Neon(데이터베이스) 만들기 — 약 10분
1. https://neon.tech 가입 → **Create project**
   - 지역: **AWS Asia Pacific (Seoul)** 또는 가장 가까운 곳
2. **Connection string**을 복사해요.
   - **Pooled connection**(주소에 `-pooler`가 들어간 것)을 고르세요.
3. 이 주소를 두 곳에 넣어요.
   - Vercel → 프로젝트 → Settings → Environment Variables → `DATABASE_URL` (Production·Preview 모두)
   - 내 PC `.env.local`에 `DATABASE_URL=...`
4. 내 PC에서 `npm run db:migrate` 실행
   - migration 001~005가 적용돼요 (회원·찜·알림·결제·담은 곳·여행 계획).

### □ 2. 로그인 비밀값
- Vercel 환경변수에 `BETTER_AUTH_SECRET` 추가
  - 값은 아무 긴 무작위 문자열이면 돼요. 만드는 법: 터미널에서 `node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"`
- `BETTER_AUTH_URL` = `https://crowdview.app`

### □ 3. 소셜 로그인 키 (하나만 해도 그 버튼이 켜져요)

| 서비스 | 만드는 곳 | 콜백(Redirect) 주소 | 환경변수 |
|---|---|---|---|
| 카카오 | developers.kakao.com → 내 애플리케이션 → 카카오 로그인 활성화 | `https://crowdview.app/api/auth/callback/kakao` | `KAKAO_CLIENT_ID`(REST API 키), `KAKAO_CLIENT_SECRET` |
| 네이버 | developers.naver.com → 애플리케이션 등록 → 네이버 로그인 | `https://crowdview.app/api/auth/callback/naver` | `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` |
| 구글 | console.cloud.google.com → API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 ID(웹) | `https://crowdview.app/api/auth/callback/google` | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` |

- 카카오: 동의 항목은 **닉네임·프로필 사진**만 (이메일은 비즈 앱만 가능).
- 키를 넣은 뒤 Vercel에서 **Redeploy** 해야 반영돼요.

### □ 4. 검색엔진 등록 (무료, 광고와 별개) — 약 20분
자세한 순서는 `docs/SETUP.md`의 "검색엔진 등록"에 있어요.
1. **Google Search Console**: 속성 추가 → HTML 태그 값을 `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`에 → 재배포 → 확인 → sitemap `https://crowdview.app/sitemap.xml` 제출
2. **네이버 서치어드바이저**: 값을 `NEXT_PUBLIC_NAVER_SITE_VERIFICATION`에 → 확인 → sitemap 제출
3. **Bing Webmaster Tools**: Google에서 가져오기(가장 쉬움) 또는 `NEXT_PUBLIC_BING_SITE_VERIFICATION`에 값

### □ 5. 신청 (승인까지 며칠 걸려요 — 미리 해 두기)
- **관광공사 외국어 TourAPI** (data.go.kr에서 "한국관광공사 영문 관광정보 서비스" 등 활용신청)
  - 외국어 명소 소개를 켤 수 있어요.
- **SK open API 장소 혼잡도** (openapi.sk.com, 선택)
  - 서울 밖과 121곳보다 많은 실시간 지점을 켤 수 있어요. 키는 `SK_OPENAPI_APP_KEY`.
- **공공데이터 운영계정 전환** (data.go.kr 마이페이지 → 활용신청 → 운영계정)
  - 하루 호출 한도가 늘어나요.
