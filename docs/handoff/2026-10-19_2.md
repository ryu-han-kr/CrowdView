## 2. 시험·도구 쓰는 법
- `npm run build && npm run e2e` (로컬, `next start`를 Playwright가 띄움). 운영 대상: `E2E_BASE_URL=https://crowdview.app npx playwright test`
- 화면 사진: `npm run e2e:screens` → `test-results/screens/<기기>/*.png`
- Lighthouse: `npx @lhci/cli@0.15.1 autorun && node scripts/lighthouse-summary.mjs`
- 로컬 서버는 `-H 127.0.0.1`로 띄우지 말 것 (언어 경로 rewrite가 308 되돌이가 됨)
- 클라이언트 컴포넌트에서 시각·요일·`localeCompare`·`toLocale*`는 언어/시간대를 명시하거나 마운트 뒤에 계산 (서버는 UTC·en)
