## 2. 바꾼 것
- **개인정보처리방침 개정 공지 (#286, 사용자 결정)**: 10/26 공지 → **11/2 시행** (불리하지 않은 변경이라 7일 전). `PRIVACY_EFFECTIVE_DATE`·`PRIVACY_NOTICE_DATE`(lib/business.ts)로 방침만 따로 날짜를 두고, 방침 화면 위에 개정 안내 상자, 부칙에 제정·개정 이력. 약관·환불정책은 10/22 그대로. 다음에 또 바꾸면 이 두 값과 `PRIVACY.revision`만 고친다
- **애드센스 사이트 확인 (#288)**: 게시자 ID `ca-pub-7282377983507574`를 Vercel 운영 `NEXT_PUBLIC_ADSENSE_CLIENT`에 넣음 → 모든 페이지에 `<meta name="google-adsense-account">`, `/ads.txt`, 광고 스크립트가 나감. 광고 단위 ID(`_SLOT_INLINE`·`_SLOT_RAIL`)가 없으면 광고 칸은 안 그린다. 사용자가 콘솔에서 '확인' 누름 → 심사 대기
- **이동 동선 (#289)**: 장소·명소·서울 지역·축제 상세에 사진 카드 '근처 가볼 곳'(`components/NearbyRail`, 우리 장소+대표 명소를 40km 안 가까운 순, 사진 위 지금 혼잡도). 장소는 오늘 시간대별 그래프 바로 아래, 명소는 숙소 링크·광고 다음(예전 글자 목록 '…의 다른 명소' 대신), 서울·축제는 숙소 링크 위
- **동선 측정**: 비콘이 페이지 종류(`lib/page-type`)를 보낸다 → `p:{종류}`(페이지뷰), `land:{종류}`(그 페이지로 들어온 방문), `deep:{종류}`(그렇게 들어와 두 번째 페이지로 넘어간 방문). `quota.mts` 맨 아래 '들어온 페이지 | 방문 | 다음 페이지로 | 비율' 표. 며칠 쌓이면 어느 페이지가 바로 나가는지 보고 다음 개선
- `scripts/ops/quota.mts`가 API 사용량 밑에 **이용 집계 표**(순방문자·방문·페이지뷰·기대수익·1인당·잠재 제휴)도 같이 보여 준다 → 관리자 화면 안 열고 `npx tsx scripts/ops/quota.mts 3`
