## 3. 내일 할 일 (경수님 10/28 요청 — 이 순서로)

1. **홈 배너 두 개를 동시에 넘기기** — 지금은 오른쪽이 반 박자 늦게(`startDelay={AUTO_HALF}`, `src/app/[lang]/page.tsx`). 둘 다 같은 시각에 넘어가게
2. **상세 페이지 사진도 살짝씩 움직이게** — 장소 상세 상단 사진 갤러리(큰 사진+4장)에 천천히 확대·이동(Ken Burns) 효과. `prefers-reduced-motion`이면 끄기, LCP 사진은 움직임 늦게 시작
3. **로딩 화면 캐릭터** — 돌아가는 로딩 표시와 캐릭터가 겹치지 않게, 캐릭터를 정중앙에. 잠자는 캐릭터의 **zzz가 움직이는 효과**(떠오르며 흐려지기). 대기 화면은 loading.tsx 말고 NavProgress 규칙 유지
4. **메인 배경 계절·날씨 효과** — 실제 날씨와 맞추기(기상청 자료 이미 있음): 눈 오는 날 눈, 비 오는 날 비, 맑은 여름 햇빛. 날씨 효과가 없을 땐 계절 기본: **겨울 눈, 가을 낙엽, 봄 풀 자라남(새싹), 여름 햇빛/비**. 가볍게(캔버스 또는 CSS, 개수 제한), 움직임 줄이기 설정 존중, 성능 점수 유지
5. **한국 기념일 디자인** — 설·추석(음력), 삼일절, 어린이날, 광복절, 한글날, 크리스마스, 새해 등 날짜에 맞춰 홈 배경·배너·캐릭터 꾸밈. 날짜 표(음력 변환 포함)를 코드로 두고 그날만 자동 적용
6. **홈 아이콘 줄이 두 번 나오는 느낌 정리** (경수님 10/28 캡처): 위 분류 아이콘 줄(공항·테마파크…내 주변)과 아래 검색창+탭(전체·실시간 장소…)+동그란 사진 칩 줄(전체·찜·명소…)이 같은 기능처럼 보여 이상함 → **아래 쪽에는 포토카드(장소 카드 목록)가 바로 나오게**, 검색창·탭·동그란 칩 기능은 **다른 곳으로 옮기기**(빼지 말고 위치 이동 — 어디로 옮길지 전후 사진으로 보여 주고 확인). 관련 파일: `src/app/[lang]/page.tsx`, `CategoryIcons`, `HomeList`
7. **계절에 맞춰 순서 바꾸기**: 겨울(12~2월)엔 스키장, 여름(6~8월)엔 워터파크가 위로. 홈 분류 아이콘·동그란 칩·추천 목록·배너 순서에 계절 가중치. 지금(10월 말~)은 스키장이 앞쪽으로. 봄·가을은 꽃·단풍 명소/축제 쪽
