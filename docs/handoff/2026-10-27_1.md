## 3. 알아 둔 것
- **CI 러너는 집 데스크탑 하나**(`home-desktop`, self-hosted `crowdview`)라 PR이 겹치면 대기열이 1시간 넘게 밀린다. 이 노트북엔 러너가 없다. `gh run list`로 대기 상태 확인. 자동 머지(`--auto`)는 저장소 설정상 불가 → 검사 통과 뒤 `gh pr merge N --squash --delete-branch`
- 저장소에 **prettier 설정이 없다** — `npx prettier --write`를 돌리면 기존 파일까지 대량으로 바뀐다(10/27 실수로 올렸다가 되돌림). 서식은 손으로 기존 스타일에 맞춘다
- 로컬에선 네이버 지도 키가 localhost 미인증이라 지도가 그림 지도(SketchMap)로 떨어진다. 미리보기 확인은 Playwright에서 `oapi.map.naver.com`을 스텁 SDK로 바꿔치기(세션 스크립트 방식: Map·LatLng·Marker·Event 빈 클래스)
- Lighthouse 로컬 실행: `CHROME_PATH=…ms-playwright/chromium-1243/chrome-win64/chrome.exe npx -y lighthouse@12 URL --only-categories=performance --chrome-flags="--headless=new" --output=json`. 관찰(빠른 망) LCP 요소를 기준으로 느린 망을 시뮬레이션하므로, **첫 프레임에 뭐가 그려지느냐**가 점수를 정한다
- Git Bash 멀티라인 치환은 CRLF 파일에서 실패 → node 스크립트로 `\r\n` 정규화 후 치환
- 다크 CSS 분리 검토 결과: `src/app/dark.css` 25KB(gz 약 5KB)를 라이트 사용자도 받지만, 분리하면 다크 사용자 첫 화면 깜빡임(동적 link) 위험 → 보류
