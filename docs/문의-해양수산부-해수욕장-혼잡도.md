# 해양수산부 문의 — 해수욕장 혼잡도(신호등) 자료 제공

## 어디로 보내나 (위에서부터 추천)

1. **공공데이터포털 '공공데이터 제공신청'** (data.go.kr → 로그인 → 데이터 요청 → 제공신청)
   - 아직 개방되지 않은 공공데이터를 공식으로 요청하는 창구. 기관이 법정 기한 안에 '제공/불가'를 답해야 한다
   - 제공기관: 해양수산부. 데이터명에 "해수욕장 혼잡도 신호등(바다여행)"
2. **국민신문고** (epeople.go.kr → 민원신청 → 해양수산부) — 담당 부서로 자동 배정
3. 해양수산부 대표전화 044-200-5114 → "해수욕장 혼잡도 신호등 담당 부서" 연결 요청 후 담당자 메일 받기

> 1·2는 온라인 양식이라 아래 본문을 그대로 붙여넣으면 된다. 회신은 보통 7~14일.

## 제목

해수욕장 혼잡도 신호등(바다여행) 자료의 공공데이터 개방(오픈 API) 요청

## 본문

CrowdView는 서울시 실시간 도시데이터, 한국공항공사·인천국제공항공사 혼잡도, 한국관광공사 관광 데이터 등 공공데이터를 모아 "지금 어디가 덜 붐비는지"를 내국인과 외국인 관광객에게 안내하는 웹 서비스입니다.

해양수산부가 '바다여행' 누리집에서 제공하는 **해수욕장 혼잡도 신호등**(해수욕장별 혼잡 단계)을 저희 서비스에서도 안내하고 싶어 아래 사항을 문의드립니다.

1. 해수욕장 혼잡도 신호등 자료를 **오픈 API 또는 파일 데이터**로 받을 수 있는지
   - 필요한 항목: 해수욕장 이름(또는 코드), 혼잡 단계, 기준 시각, (가능하면) 추정 인원
2. 받을 수 있다면 **신청 방법과 이용 조건**(출처 표시 방식, 호출 횟수 제한 등)
3. 현재 개방 계획이 없다면, 공공데이터포털에 개방을 검토해 주실 수 있는지
4. 해수욕장 운영 기간(개장~폐장) 외의 기간에도 자료가 제공되는지

받은 자료는 출처(해양수산부)를 밝히고 무료로 안내하며, 원 자료를 변형해 재판매하지 않습니다.
