# CrowdView 경쟁 분석 · 외국인 관광객 유치 전략 (2026-10-26)

> 사용자 요청 7번(차별화 전략, 외국인용 UI·기능 조사). 웹 조사 기반 보고서. 수치는 출처 기사 기준이며 일부는 추정 표시.

## 0. 핵심 요약

1. **시장은 커지고 있다.** 2025 방한 외래객 1,894만 명(+15.7%, 역대 최대), 2026년 1~9월 1,711만 명(+21.5%). 평균 체류는 7.8일 → 6.5일로 줄어, 짧은 일정에서 줄 서는 시간을 아끼려는 수요가 크다.
2. **외국인 불편의 중심은 '디지털 요새'.** 레딧 분석(야놀자리서치): 디지털 27.8%, 관광정보 16.4%, 교통 13.1%, 결제 12.0%. 세부로는 가입·본인인증 13.1%, 길찾기 10.3%. 로그인 없이 바로 쓰는 다국어 정보 서비스인 CrowdView는 이 문제를 정면으로 겨냥한다.
3. **외국어 실시간 혼잡 정보는 사실상 빈자리.**
   - 서울시 실시간 도시데이터는 한국어 중심.
   - 네이버·카카오는 영어 검색이 약하다.
   - Google 지도는 2026년 2월 정밀지도 반출이 조건부 승인됐지만, 길안내 출시는 아직 확인되지 않았다.
   - 놀이공원 대기는 Queue-Times가 롯데월드·에버랜드를 영어로 무료 제공 → 직접 경쟁자.
4. **중심축: "정보를 본 순간 바로 행동하게".** "지금 붐빈다 → 언제 가면 한산한가 → 줄 건너뛰는 상품(Q-Pass·Magic Pass)·eSIM·교통 예약"으로 잇는다. AI 요약이 붙은 검색어는 클릭이 58~61% 줄어, **AI가 대신 답할 수 없는 실시간·예측 데이터 페이지**가 SEO에서 지킬 수 있는 자산이다.
5. **3개월 최우선 3가지**
   - ① 명소별 "지금 붐비나요? / 언제 가야 하나요?" 다국어 페이지 대량 생성(프로그래매틱 SEO)
   - ② 요일×시간 "가기 좋은 시간" 히트맵
   - ③ 놀이공원·공항 화면의 상황에 맞춘 제휴 버튼

| 국적 (2025년 11월) | 중국 37.8만, 일본 36.3만, 대만 15.8만, 미국 13.3만 | 5개 언어 구성이 적절 |

| 사전 관심 활동 | 음식 61.7%, 쇼핑 57.3%, 자연 35.6% | 성수·명동 등 쇼핑 핫스팟 혼잡 정보가 중요 |

| K-콘텐츠 | 케이팝 데몬 헌터스 촬영지 순례: 낙산공원·북촌·N서울타워·코엑스·명동 | 대부분 서울 121곳과 겹쳐 기존 데이터 재활용 가능 |

## 2. 경쟁 서비스

| 서비스 | 하는 일 | 강점 | 약점 / CrowdView의 틈 |
|---|---|---|---|
| Google 지도 (인기 시간대) | 붐비는 시간 그래프, 실시간 붐빔 | 외국인 기본 앱 | 한국은 이용자가 적어 데이터가 얕을 가능성(추정), 상대값만 보여 줌. **위협:** 12~24개월 안에 크게 개선될 수 있어, 그 전에 '한국 특화 + 예측' 자리를 굳혀야 함 |
| 서울 실시간 도시데이터 | 121곳 혼잡·12시간 예측 | 공식, 무료 API | 한국어 중심이고 외국인은 존재를 모름 → **외국어·쉬운 설명·행동 제안으로 다시 포장하는 것이 핵심 기회** |
| VisitKorea / Visit Seoul | 공식 여행 정보 | 공신력, 다국어 | 실시간 혼잡이 핵심 기능이 아님 |
| 네이버 지도 | 국내 1위 지도, 리뷰 다국어 번역 | 외국인 이용률 56.2%, 길안내 정확 | 영어 장소명 검색 부정확, 관광 맥락의 혼잡 예측 약함 |
| 카카오맵 | 길찾기, 지하철 도착 정보 | 대중교통 정밀 | 영어는 일부만, 관광지 혼잡 기능 없음 |
| Queue-Times | 전 세계 놀이공원 대기(롯데월드·에버랜드 포함) | 영어, 무료, 과거 달력 | **직접 경쟁자.** 한국 맥락(날씨·방학·공휴일 예측), 다국어, 티켓 연결이 없음 |
| TouringPlans | 디즈니 혼잡 달력, 연 $24.97 구독 | 유료 모델 검증됨 | 한국 미지원 → **Plus의 참고 모델**(1년 혼잡 달력·최적 동선) |
| Flightqueue | 인천공항 보안검색 대기 | 영어 검색에 노출 | 수치가 들쭉날쭉해 신뢰도 낮음 → 공식 출국장 데이터를 가진 CrowdView가 우위 |
| Klook | 티켓·패스·eSIM 판매, 관광공사 협약 | 에버랜드 Q-Pass 단독 판매 | 혼잡 정보가 없어 "언제 갈지"를 모름 → CrowdView와 **보완 관계** |
| Trip.com | 항공·호텔·투어 | 중화권 강세 | 실시간 데이터 없음 |
| Creatrip | 외국인 전용 플랫폼, 월 180만 이상 | 한국 번호 없이 주문·예약 대행 | 혼잡 정보 없음 → 협업 대상 |
| Trazy | 외국인 대상 투어·티켓 | 놀이공원 패키지 | 대기 정보 없음 |
| 트리플 / NOL | 외국인용 '인터파크 글로벌 by NOL' | 대기업 자본 | 혼잡 같은 틈새 기능은 느림 |
| 마이리얼트립 | 국내 OTA, 인바운드 강화 선언 | 상품 폭 | 판매처일 뿐 정보 서비스가 아님 |

**판단:** 혼잡·예측 정보와 티켓·eSIM 판매를 한 화면에서 잇는 다국어 서비스는 아직 없다. 판매 플랫폼은 "언제 갈지"를 모르고, 데이터 플랫폼은 "외국어"와 "다음 행동"이 없다. CrowdView는 이 사이를 노린다.

| 관광정보 | 16.4% | 명소별 "지금 혼잡 + 가기 좋은 시간 + 근처 대안"을 한 장에 |

| 숙박 | 신고 1위 | 신뢰할 수 있는 OTA(아고다 등)로 연결 |

## 4. 기능 아이디어 (효과·작업량)

작업량은 1인 개발 기준: S = 1주 이내, M = 2~3주, L = 4주 이상.

| 순위 | 기능 | 효과 | 작업량 | 이유 |
|---|---|---|---|---|
| 1 | 명소별 프로그래매틱 SEO 페이지 ("Is Gyeongbokgung crowded right now?", "Best time to visit Lotte World", ja·zh 포함) | ★★★★★ | M | 600개 이상 페이지 가능. 실시간 숫자는 AI 요약이 대신 답할 수 없음 |
| 2 | "가기 좋은 시간" 히트맵 (요일×시간) | ★★★★★ | M | 쌓은 데이터가 남이 따라 할 수 없는 고유 자산 |
| 3 | 상황 제휴 버튼 (대기 60분↑ → Q-Pass, 공항 혼잡 → AREX·eSIM) | ★★★★★ (수익) | S | 불편한 순간에 해결책을 보여 줘 전환율이 가장 높음 |
| 4 | 공유용 혼잡 카드 (동적 OG 이미지, LINE·WhatsApp·카카오) | ★★★★ | S | 입소문 경로 |
| 5 | 외국인 생존 허브 (eSIM·교통·결제·지도·K-ETA) | ★★★★ | S | 불편 1~4위 해결, eSIM 수수료 최대 20% |
| 6 | 인천공항 출발 시각 계산기 | ★★★★ | S~M | 경쟁사 신뢰도가 낮은 틈 |
| 7 | K-콘텐츠 촬영지 혼잡 컬렉션 | ★★★★ | S~M | 기존 데이터 재활용, SNS 확산 |
| 8 | 지도 바로가기·한글명 복사 | ★★★ | S | 길찾기 불편 즉시 해결 |
| 9 | 성수 팝업 트래커 | ★★★★ | M (운영 부담) | 주 1회 갱신으로 제한 |
| 10 | PWA·오프라인 일정 | ★★★ | M | 재방문 경로 |
| 11 | 한산해지면 알림 (Plus) | ★★★ | M~L | 재방문·유료 전환 |
| 12 | 놀이공원 1년 혼잡 달력 (한·중·일 공휴일 반영) | ★★★★ | M | TouringPlans 모델 |
| 13 | 일정 내보내기 (.ics) | ★★ | S | 저장·공유 |
| 14 | 레딧 질문에 데이터로 답하기 | ★★★ | S (지속) | 홍보가 아니라 도움 되는 답으로 |

**하지 말 것:** 번역·길안내를 직접 만들기, 범용 여행 블로그 글 대량 작성(AI 요약 때문에 클릭이 크게 줄어드는 영역).

## 5. 수익화 적합도

| 제휴 상품 | 전환을 이끄는 기능 | 전환력 |
|---|---|---|
| Klook 에버랜드 Q-Pass·롯데월드 Magic Pass | 놀이공원 실시간 대기·혼잡 달력 | 매우 높음 |
| eSIM (Klook·Trip.com) | 생존 허브·공항 화면 | 높음 (수수료 최고 수준) |
| 근교 투어 (Klook·GetYourGuide) | "서울이 붐비는 날 근교로 피하기" | 중~높음 |
| 한복 대여·경복궁 야간개장 | 경복궁 히트맵 | 중간 |
| 아고다 숙소 | "조용한 동네에 묵기" | 중간 |
| AREX·공항 리무진 | 출발 계산기 | 중간 |

**원칙:** 혼잡 정보 1개에 해결 상품 1개만 붙인다. 언어별 기본 제휴처를 나눈다: 중국어는 Trip.com·Klook, 일본어는 Klook, 영어는 GetYourGuide·Klook.

## 7. 리스크

- **Google 지도 길안내 출시:** CrowdView는 지도가 아니라 "언제 갈지"를 판단해 주는 도구로 자리 잡아야 겹치지 않는다.
- **Queue-Times 무료 대기:** 예측·공휴일 반영·티켓 연결·다국어로 차별화해야 한다.
- **AI 요약:** 실시간·예측 데이터와 구조화 데이터에 집중한다.
- **출처 표기:** 서울 도시데이터는 공공누리 출처 표기, Queue-Times는 약관 확인.
- **운영 부담:** 손으로 갱신해야 하는 기능은 최소화한다.
- **인프라 비용:** 페이지 수가 늘어나면 빌드·ISR 호출도 는다(Upstash 한도 초과 이력 있음).
