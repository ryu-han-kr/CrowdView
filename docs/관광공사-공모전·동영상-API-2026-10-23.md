# 관광공사 공모전 수상작·관광 동영상 API 확인 (2026-10-23)

둘 다 우리 키(`DATA_GO_KR_KEY`)로 정상 응답해요. 공공누리 제1유형(출처 표시하면 상업 이용 가능)이에요.

## 1. 관광공모전(사진) 수상작 — `B551011/PhokoAwrdService`
- 기능: `phokoAwrdList`(목록), `phokoAwrdSyncList`(동기화), `ldongCode`(법정동)
- 전체 **90장**뿐이에요. `keyword` 검색은 안 돼요(0건). 필드: 제목, 촬영지(`koFilmst`), 작가, 수상 내역, 키워드, 원본·썸네일 주소, 촬영 연월
- 우리 장소 45곳과 겹치는 건 **해운대 1곳(2장: 해운대 일몰, 빛축제 거리의 아침)** 뿐이에요.
- 판단: 대표 사진 보강 효과가 작아요. 해운대 2장만 격자 사진에 더할 수 있어요(작가 이름 표시 필요).

## 2. 관광 동영상 — `B551011/VideoService`
- 기능: `videoList`(목록), `videoDetailInfo`(상세), `videoSyncList`, `lclsSystmCode`(분류), 법정동
- 전체 **1,074개**(2026-08 등록, 대부분 '2026 지역관광 고품질 드론 콘텐츠'). 목록에는 썸네일만 있고, 영상 주소(HLS `orgCdnUrl`)·설명·촬영지는 상세에서 나와요.
- 우리와 겹치는 곳:
  - 장소 45곳 중 3곳: 경주월드(캘리포니아비치 포함), 이월드
  - 명소 117곳 중 12곳: 광안리해수욕장, 감천문화마을, 자갈치시장, 이월드 83타워, 팔공산, 대왕암공원, 공주 공산성, 동궁과 월지, 첨성대, 거제 바람의 언덕, 마이산, 화엄사
- 판단: 장소·명소 상세에 "드론 영상" 썸네일(눌러서 재생)을 넣을 수 있어요. 화면이 바뀌는 일이라 전후 비교를 보고 결정해요. 넣는다면 목록은 스크립트로 한 번 받아 JSON으로 두고(하루 호출 0), 재생은 관광공사 CDN을 그대로 써요.
