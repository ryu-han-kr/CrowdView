### 호출이 주기보다 많았던 이유 (10/21)
1. **배포 빌드**: 빌드 중에는 받은 값을 Redis에 저장하지 못하게 막아 둬서, 빌드 작업자마다 같은 API를 다시 부르고 그 수가 한도 집계에 잡혔다 (10/21 운영 배포 51번). → 빌드 중엔 묵은 값이 있으면 원본을 부르지 않게 고침
2. **실패 재시도**: 실패하면 5분마다 다시 불렀다(10/22 아침 에어코리아 제주가 실패 표시 상태). → 연속 실패면 5분 → 15분 → 1시간으로 늘림
