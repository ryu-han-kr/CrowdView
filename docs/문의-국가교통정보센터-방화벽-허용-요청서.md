## 1. 먼저 정해야 하는 것 — 출발지(우리 서버) IP

센터는 **고정 출발지 IP**를 허용 목록에 넣는다. 지금 CrowdView 서버(Vercel, icn1 = AWS 서울)는 **나가는 IP가 매번 바뀌어** 그대로는 적을 수 없다.

| 방법 | 비용 | 장단점 |
|---|---|---|
| A. Vercel Static IPs (Pro) | **월 $100/프로젝트** + Private Data Transfer | 설정만 하면 끝(Settings → Networking → Manage Active Regions, 지역당 IP 2개). 도로 카드 하나에 쓰기엔 비쌈. Spend Management $50 한도 초과 |
| B. 고정 IP 중계 서버(릴레이) | Oracle Cloud Always Free(서울·춘천 리전, 고정 공인 IP) 0원 / Lightsail·Vultr 서울 월 $3.5~5 | 작은 서버 하나에 `GET /its?…` → openapi.its.go.kr:9443 으로 넘기는 프록시만 띄움(토큰으로 보호). Vercel 함수는 이 중계 서버만 부른다. 사용자 목표(직접 운영 클라우드)와 맞고, 나중에 다른 '국내 IP만 허용' API에도 재사용 |
| C. 그냥 두기 | 0원 | 도로 카드는 지금처럼 한국도로공사(고속도로)만. 서울 시내는 서울시 도로 소통으로 대체 중 |

추천: **B**. 요청서의 출발지 IP는 중계 서버의 고정 공인 IP로 적는다. (A를 고르면 Vercel 대시보드에 표시되는 IP 2개를 적는다.)
