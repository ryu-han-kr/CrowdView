## 1. 지금 서비스가 하는 일 (한눈에)

| 영역 | 내용 |
|---|---|
| 실시간 혼잡도 | 서울시 실시간 도시데이터(121곳), 인천·김포 등 공항(출국장·시간대 승객), 에버랜드·롯데월드 대기시간, 부산 생활인구 |
| 예측 | 요일·시간·날씨·공휴일 패턴 예측, 서울시 12시간 공식 예보, 지하철 승하차 패턴, 축제는 작년 방문객 기반 지역 방문 증가 예상 |
| 여행 | 지역 여행(/explore, 17개 시도 대표 명소 66곳 + 관광공사 명소 1,856곳), 전국 축제, 서울 여행 가이드(맛집·체험·예약), 근처 숙소 링크(야놀자·여기어때·네이버·에어비앤비·트립닷컴·부킹닷컴) |
| 코스 추천 | 붐비는 시간을 피하는 코스(지하철 이동시간, 점심·저녁, 담은 곳 넣기, 내일·주말 출발, 공유 링크·미리보기 이미지·캘린더·날씨 경고) |
| 편의 | 내 주변 화장실·와이파이, 담기(☆), 혼잡 알림(서울 119곳), 근처 한산한 대안 |
| 신뢰 공개 | `/methodology`(데이터 출처·계산 방식), `/accuracy`(예측 정확도 매시간 측정) |
| 다국어 | 한국어·영어·일본어·중국어(간체·번체), 축제 이름은 Papago 번역 |
| 회원·결제 | 로그인·Plus 결제(포트원)·약관·환불정책 — **코드 완성, 키 미입력으로 꺼져 있음** |
| 운영 | 10분마다 수집(Vercel Cron), 매일 비용 리포트 PDF, 디스코드 알림, `/api/health`, 요청 제한, 브라우저 오류 수집, API 일일 한도 보호 |
| 검색 노출 | sitemap·hreflang·구조화 데이터, 서버 렌더링 목록, llms.txt·공개 API(GEO), Bing·네이버 IndexNow |

## 4. 남은 할 일

### 개발 (순서대로)
1. SK open API 키 → 더 많은 실시간 지점
2. 1~2주 뒤 `/accuracy` 숫자 보고 패턴 예측 보정
3. 관광공사 외국어 TourAPI 신청 후 외국어 소개 → 외국어 /spot 공개

### 사용자가 할 일
- **검색엔진 등록 (무료)**: Google Search Console·네이버 서치어드바이저·Bing에 등록하고 sitemap 제출. 순서는 `docs/SETUP.md` 참고
- **Neon(Postgres)**: 만들고 `npm run db:migrate` 실행
- **Vercel 환경변수**: 로그인·포트원·VAPID·ADMIN_EMAILS·MAIL_FROM
- **GitHub Secrets**: `DATA_GO_KR_KEY`
- **사업자 정보**: 통신판매업 신고번호·주소·고객센터를 `src/lib/business.ts`에, 개인정보처리방침 시행일 확정
- **신청**: 공공데이터 운영계정 전환, 숙소 제휴, 관광공사 외국어 TourAPI
- **(선택)** UptimeRobot에 `/api/health` 5분 간격 감시 등록
- **10/23쯤** Upstash 사용량 확인
- **다음 주 월요일** IndexNow 자동 실행 로그 확인 (Bing 쪽 403이 계속되는지)
