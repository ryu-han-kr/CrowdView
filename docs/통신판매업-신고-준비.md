1. **구매안전서비스 이용확인증** 받기 — 토스페이먼츠 상점관리자(https://app.tosspayments.com, 상점아이디 `q_crowdvvqaj`)에서 내려받기. 메뉴를 못 찾으면 고객센터 1544-7772 또는 support@tosspayments.com 에 "통신판매업 신고용 구매안전서비스 이용확인증" 요청
2. **정부24**(https://plus.gov.kr) 로그인 → "통신판매업 신고" 검색 → 신청 (관할: 서울 강남구청)

4. **등록면허세** 납부 안내가 오면 납부 (서울 자치구: 인구 50만 이상 시 기준 40,500원 — 2025년 기준 금액, 고지서 금액이 정답)
