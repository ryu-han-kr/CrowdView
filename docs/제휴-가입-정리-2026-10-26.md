# 제휴(어필리에이트) 가입 정리 — 2026-10-26

사이트에는 숙소·투어 링크 칸(`components/StayLinks`)과 제휴 꼬리표(`lib/affiliate.ts`)가 이미 있다. 가입 후 받은 값을
Vercel 환경변수 `NEXT_PUBLIC_AFF_<업체>`에 넣고 재배포하면 링크에 붙고 rel="sponsored"·제휴 표시 문구가 나온다.

## 제휴 대행사(네트워크)로 가입하는 경우
Klook은 10/26 자체 프로그램으로 가입됨 (대행사 불필요). Klook·KKday는 Involve Asia, GetYourGuide·Klook은 Travelpayouts 같은 대행사로 가입하라는 안내가 많다.
대행사 링크는 `?aid=…` 꼬리표가 아니라 **대행사 주소로 감싸는 링크**(예: `https://invl.io/…?url=원래주소`)라서
지금 `lib/affiliate.ts`(꼬리표 붙이기)로는 안 된다 → 그렇게 가입하면 링크 하나를 받아 '감싸기' 방식을 추가한다 (작은 코드 변경).

## 값을 받으면
1. Vercel 운영 환경변수에 넣기 (값은 화면에 출력하지 않음) → 재배포
2. 운영에서 링크 끝에 값이 붙는지, '일부는 제휴 링크…' 문구가 나오는지 확인
3. 며칠 뒤 `npx tsx scripts/ops/quota.mts`의 제휴 클릭·기대수익과 업체 보고서를 비교해 `lib/revenue.ts` 가정값(전환율·수수료) 고치기
