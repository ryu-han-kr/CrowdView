# AI·검색 활용 계획 (2026-10-22)

> Claude API 크레딧 100달러 + Brave Search(무료) + Tavily(무료)로 검색 품질, 혼잡도 정확도, 장소 정보를 높이는 방법.
> 원칙: 검색은 무료 API로 모으고, Claude는 "모은 자료를 읽고 정리·판단"하는 데만 쓴다. 하루 정해진 횟수만 돌려 비용을 고정한다.

## 1. 지금 연결된 것

| 도구 | 쓰는 곳 | 한도 (코드에 걸어 둠) |
|---|---|---|
| 네이버 검색어 트렌드 | 요즘 뜨는 곳 순위(최근 7일 검색량·증가율) | 월 5만 건 중 하루 약 15건 |
| Brave Search 뉴스 | 장소별 최근 소식(장소 상세), 시즌 이벤트 찾기(요즘 뜨는 곳) | 하루 30건, 월 900건 (`BRAVE_DAILY_LIMIT`, `BRAVE_MONTHLY_LIMIT`) — 매달 $5 무료 크레딧(약 1,000건) 안 |
| Tavily | Brave가 실패하거나 한도일 때 대신 | 하루 30, 월 1,000크레딧 (`TAVILY_DAILY_LIMIT`, `TAVILY_MONTHLY_LIMIT`) |
| Claude API | `ANTHROPIC_API_KEY`를 넣으면 켜짐: 화제 행사 웹 검색(하루 1번) | 하루 1번 |

모두 `/api/cron/trending`(매시 15분, 하루 한 번만 실제 계산)에서 돈다. 한도의 90%에 닿으면 그날은 멈추고 저장된 값을 쓴다.

## 2. Claude 크레딧 쓰는 곳 (우선순위 순)

### ① 화제 행사 정리 (이미 코드 있음, 키만 넣으면 됨)
- 매일 아침 Claude가 웹 검색으로 "지금 한국에서 화제인 축제·테마파크 시즌 이벤트" 8~10개를 날짜·장소·링크와 함께 고른다 (`src/lib/ai-events.ts`).
- 우리 장소(에버랜드 등)면 장소 상세로, 아니면 공식·기사 링크로 홈 '요즘 뜨는 곳'에 올라간다.
- 예상 비용: 하루 0.1~0.3달러 → **월 3~9달러**.

### ② 검색 결과 → 구조화 (Brave·Tavily 결과를 Claude가 읽기)
- 지금은 뉴스 제목에 '할로윈·축제·시즌' 같은 낱말이 있으면 이벤트로 본다 (규칙 기반, 틀릴 수 있음).
- Claude에게 장소별 뉴스 3~5개를 한 번에 주고 "진행 중인 행사 이름·기간·운영시간 변경·휴장·입장 제한"을 JSON으로 뽑게 하면 정확해진다.
- 30곳을 한 요청으로 묶으면 하루 1번. Batch API(50% 할인)로 돌리면 **월 2~4달러**.

### ③ 혼잡도 정확도 보정 (가장 효과 큼)
- 뉴스·검색 결과에서 "오늘 혼잡 신호"를 뽑는다: 대형 행사·공연, 입장 마감·매진, 무료 개방일, 시설 공사·휴장, 교통 통제.
- Claude가 장소마다 `+15(붐빔 요인) / -20(휴장·공사)` 같은 보정값과 이유를 내고, 예측 모델(`lib/crowd/model`)의 이벤트 요인으로 넣는다. 화면에는 "오늘 ○○ 행사로 평소보다 붐빌 수 있어요"로 보인다.
- 주 1회: R2에 쌓인 실측·예측 차이(`npm run archive:read`)를 Claude가 읽고 장소별로 어디가 계속 틀리는지, 요일·날씨 계수 조정안을 낸다 (사람이 보고 반영). Batch API로 **월 1~2달러**.

### ④ 코스 추천 자연어 입력
- "애니 굿즈샵이랑 카페 들르는 한산한 코스, 차로 이동" 같은 문장을 Claude가 관심사·이동수단·필수 장소로 나눈다.
- 장소 후보는 카카오 로컬 검색(카페·백화점·플래그십·애니 매장)과 Brave 검색으로 찾는다. 요청마다 1번이라 이용자 수에 비례 → 하루 한도(예: 200회)를 건다. 이용자 100명/일 기준 **월 5~10달러**.

### ⑤ 장소 정보 최신화 (주 1회)
- 공식 사이트 안내(운영시간·휴무·요금 변경)를 Claude 웹 가져오기로 읽어 바뀐 것만 알려 준다 → 디스코드 알림, 사람이 확인 후 반영. **월 1~2달러**.

### 합계
| 항목 | 월 예상 |
|---|---|
| ① 화제 행사 | 3~9달러 |
| ② 검색 구조화 | 2~4달러 |
| ③ 혼잡 보정 + 주간 분석 | 2~4달러 |
| ④ 코스 자연어 | 5~10달러 |
| ⑤ 정보 최신화 | 1~2달러 |
| **합계** | **약 13~29달러 → 100달러로 3~7개월** |

## 3. 모델·비용 원칙
- 기본 모델은 Claude Opus 5.5(입력 100만 토큰당 4달러, 출력 20달러). 정리·분류처럼 쉬운 일은 effort를 `low`로 낮춘다.
- 더 아끼려면 ②·③처럼 대량으로 정리하는 일에 Claude Haiku 5.5(입력 0.1달러, 출력 0.5달러)를 쓸 수 있다. 품질을 한 번 비교해 보고 정한다.
- 매일 같은 앞부분(설명문)은 프롬프트 캐시로 90% 싸게. 급하지 않은 일은 Batch API(50% 할인).
- 모든 호출은 `lib/api-quota`처럼 하루 횟수를 세고, 크레딧이 바닥나면 AI 없이 규칙 기반으로 돌아간다 (지금 상태).

## 4. 해야 할 일 (사용자)
1. Claude 콘솔(console.anthropic.com)에서 크레딧을 받은 뒤 API 키를 만든다.
2. Vercel Production 환경변수 `ANTHROPIC_API_KEY`에 넣고 재배포한다.
3. 콘솔 → Limits에서 월 사용 한도를 30달러 정도로 걸어 두면 실수로 크레딧을 다 쓰지 않는다.
4. 넣은 뒤 `/api/health`의 `keyProbe.anthropic.ok`가 true인지 확인한다 (모델이 확인해 줄 수 있음).
