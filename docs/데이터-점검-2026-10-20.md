# 데이터 점검 — 2026-10-20

모든 장소(혼잡도 카드 37곳)와 대표 명소(사진 카드 66곳)를 같은 항목으로 맞춘 결과와, **아직 비어 있는 것** 목록이다.
표에서 **굵게** 표시한 칸이 빈 곳이다. 다시 만들 때: `npx tsx scripts/korea-data/gallery.mts` (사진), `npx tsx scripts/korea-data/spot-kto.mts` (관광공사 집중률 이름).

## 2. 아직 비어 있는 것 (정리)

### 장소
- **김해공항 사진 1장**: 관광공사에 사진이 없음. 공항 화면은 사진을 크게 쓰지 않아 영향 적음 → 위키미디어에서 찾아 넣을 후보
- **스키장 9곳 관광공사 콘텐츠·집중률 없음**: 관광공사에 스키장이 '숙박/레포츠' 따로 등록돼 있어 지금 연결이 안 됨 → 콘텐츠 ID를 손으로 찾아 넣어야 함 (사진은 이름 검색으로 이미 채움)
- **집중률 없음 (5곳)**: 부산불꽃축제·서울빛초롱축제(행사라 목록에 없음), 광주패밀리랜드, 캐리비안 베이, 경주월드 캘리포니아비치
- **방문객 성별·연령**: 부산 2곳(해운대·부산불꽃)만. 서울은 서울시 도시데이터에 성별·연령 비율이 있어 붙일 수 있음 (다음 작업 후보)
- **운영 시간**: 관광공사 글을 읽어 오지만 '확인됨' 표시는 일부만 → 공식 홈페이지 기준 점검 필요
