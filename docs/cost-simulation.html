기존 명세서 표와 달라진 점

  • 100명도 프론트 서버가 무료가 아닙니다. Vercel 무료(Hobby) 플랜은 상업적 이용이 금지되고, Cron이 하루 1회만 돌아서 명세서의 10분 주기 갱신이 불가능합니다. 처음부터 Pro($20)가 필요합니다.
  • 부가세가 가장 큰 비용입니다. 500원 중 약 45원(9.1%)은 부가세로 납부해야 하며, 인프라비 전체보다 큽니다.
  • PG 수수료는 3.3%가 아니라 약 3.74%입니다. 토스페이먼츠 카드 3.4%에 VAT 10%가 별도로 붙고, 연관리비 110,000원(VAT 별도)도 있습니다.
  • 카드 결제는 묶어도 수수료율이 같습니다. 카드는 정률(%)이라 월 500원이든 연 6,000원이든 수수료 비율은 동일합니다. 묶음 결제가 확실히 이득인 경우는 건당 최저 수수료가 있는 계좌이체(500원 결제 시 220원, 44%)이고, 그 밖에 결제 실패·해지 관리 측면의 이점이 있습니다.
  • AI 챗봇은 이용자 수에 비례해 늘어나는 비용입니다. 1만 명 기준 월 약 14만 원(Haiku)으로, 출시할 때는 이용 횟수 제한이나 캐싱이 필요합니다.

산정 근거

네이버 지도 (NAVER Cloud Maps)

  • Web Dynamic Map: 대표 계정 기준 월 10,000,000건 무료, 초과분 건당 0.1원
  • 1만 명 × 15회 = 15만 건으로 무료 한도의 1.5%
  • 장소 좌표를 직접 갖고 있어 Geocoding은 쓰지 않음 (사용 시에도 월 300만 건까지 무료)
  • 대표 계정이 아닌 계정으로 호출하면 처음부터 과금되니 계정 하나로만 운영

Vercel Pro (프론트·API·Cron)

  • 좌석당 월 $20, 같은 금액의 사용량 크레딧 포함
  • 데이터 전송 1TB, Edge 요청 1천만 건 포함
  • 1만 명 × 40페이지뷰 = 월 40만 페이지뷰로 포함량 안에서 처리 가능한 규모
  • Pro부터 Cron을 분 단위로 실행 가능

Supabase (DB·인증)

  • Free: DB 500MB, MAU 5만, 1주 미사용 시 일시정지
  • Pro: 월 $25, DB 8GB, MAU 10만, Micro 컴퓨트 크레딧 $10 포함
  • 1만 명 구간은 Small 컴퓨트로 올린다고 보고 +$5 반영
  • 혼잡도 이력 저장 시 연 약 1GB 수준으로 8GB 한도 안

Upstash Redis (캐시)

  • 무료: 월 50만 명령 · 종량제: 10만 명령당 $0.20
  • Cron: 11개 장소 × 읽기·쓰기 2회 × 월 4,320회 = 약 9.5만 명령
  • 무료 한도를 넘으면 전체 명령을 종량제로 계산 (보수적 가정)
  • 캐시 조회를 MGET 한 번으로 묶으면 1만 명에서도 거의 무료 한도 안

결제 (토스페이먼츠)

  • 카드 3.4%, 계좌이체 2.0% (건당 최저 200원), 모두 VAT 별도
  • 연관리비 110,000원 + VAT를 12개월로 나눠 반영
  • 영세·중소 사업자 우대 요율은 국세청 자료로 매년 자동 적용되므로, 첫해는 일반 요율로 계산
  • 정기결제(빌링) 계약 조건은 별도 확인 필요

무료로 두는 항목

  • 서울 열린데이터광장 실시간 도시데이터, 공공데이터포털, 기상청 API: 무료 (호출 한도 있음)
  • 혼잡도 예측 모델: 서버에서 직접 계산해 별도 비용 없음
  • 웹 푸시 알림, 오류 모니터링 무료 플랜
  • 도메인은 .com 기준 연 약 2만 원을 월로 나눠 반영
  • 앱스토어 출시 시에는 인앱결제 수수료 15~30%가 추가되어 계산이 크게 달라짐
